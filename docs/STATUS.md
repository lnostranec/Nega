## 2. Что осталось сделать

### Блокеры запуска

1. **Домен.** `*.vercel.app` режется DPI на российских сетях: сайт открывается только через VPN. Нужен домен (`.ru`, 200–400 ₽/год) → привязать к Vercel (A `76.76.21.21`, CNAME `cname.vercel-dns.com`) → проверить без VPN → обновить `NEXT_PUBLIC_SITE_URL`.
2. **Почта клиентам.** `EMAIL_FROM=onboarding@resend.dev` — тестовый отправитель, письма уходят только владельцу аккаунта. Нужен домен + верификация в Resend (SPF/DKIM) → `EMAIL_FROM=Nega <orders@домен>`.
3. **`NEXT_PUBLIC_SITE_URL`** обновить после появления домена: от него зависят ссылки в письмах и возврат после оплаты.
4. **Вебхук ЮKassa** — после смены домена обновить URL уведомлений в кабинете: `https://домен/api/payments/yookassa`.

### Перед запуском

5. **Регион функций Vercel → `fra1`** — сейчас США, каждый запрос к базе в Москве идёт через Атлантику.
6. **Cron раз в сутки** (лимит Hobby): письма и снятие просроченных резервов могут отставать до 24 часов.
7. **Контент:** слайды меняет заказчица; в карточках демо-фото; юридические реквизиты — нет р/с, банка, БИК и адреса склада (`src/lib/seller.ts`).
8. **Юридические тексты:** FAQ и `/delivery` устарели (обещают несуществующие способы доставки, «вход по телефону»).

### Позже

11. **Переезд на российский хостинг** (152-ФЗ + стабильность): VPS/платформа приложений в РФ, база уже в Yandex Cloud.
12. **Долями и Яндекс Доставка** — не настроены (нет ключей/токена); Долями убрана из оплаты.
13. **Возвраты** для Долями/Яндекс Пэя не реализованы — сейчас возврат автоматически делается только через ЮKassa.
14. **Аналитика и мониторинг:** `NEXT_PUBLIC_YANDEX_METRIKA_ID`, `SENTRY_DSN` не заданы.
15. **Оптимизация шрифта:** TTF 727 КБ → woff2/сабсет (~100–150 КБ).
16. **Документация:** `README.md` и `PATCHNOTES.md` устарели; `LAUNCH.md` частично.
17. **Уведомления ВК — передача заказчице.** Заменить `VK_PEER_ID` на её id можно только после того, как она сама напишет сообществу, иначе ВК вернёт ошибку 901 и заявки перестанут доходить. Порядок описан в `docs/VK-NOTIFICATIONS.md`.

## 3. Ограничения и особенности

- **Доступ к проду только через VPN** — следствие блокировки `*.vercel.app`. Заказчицу предупредить.
- **Порт 5432 у Yandex закрыт**, подключение идёт через пулер 6432 (Odyssey). Отсюда `pgbouncer=true` и ограничение пула в коде.
- **Vercel регион по умолчанию** — США, что даёт лишние 100–150 мс на каждый запрос к базе.
- **Уведомления уходят в ВКонтакте**, а не в Telegram (`docs/VK-NOTIFICATIONS.md`). Сейчас — в личный диалог `VK_PEER_ID=140141604`; сообщество не может написать человеку первым, поэтому каждый новый получатель должен сам написать сообществу.
- **Тестовые заказы в базе:** `NEGA-62100045` (оплачен, 100 ₽, Сплит), `NEGA-63713847` (отменён).

## 4. Как работать с проектом

```bash
npm install                 # зависимости (шрифт уже в репозитории)
npx prisma migrate deploy   # применить миграции
npm run db:seed             # демо-данные и админ
npm run dev                 # http://localhost:3000
npm run build               # прод-сборка
npm test                    # 37 тестов
```

Переменные окружения — в `.env` (в git не попадает). На Vercel они заданы для Production; для Preview часть отсутствует.

Полезные документы:

- `docs/MEDIA-STORAGE-SETUP.md` — настройка S3-хранилища.
- `docs/VK-NOTIFICATIONS.md` — уведомления в ВКонтакте: `peer_id`, ограничения, переключение на заказчицу.
- `docs/EMAIL-CRON-SETUP.md` — Resend и cron.
- `LAUNCH.md` — чеклист запуска.
- `ИНСТРУКЦИЯ-ДЛЯ-ЗАКАЗЧИКА.md` — что делать заказчице.
