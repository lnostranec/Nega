## Бизнес-задача (кратко)

Магазин женского белья (~200–500 товаров):

1. **Сайт:** каталог, поиск, карточки, корзина, оформление заказа
2. **Личный кабинет:** ФИО, телефон, баланс баллов за покупки
3. **Оплата:** карта, Долями, Яндекс Сплит (ключи — от заказчика)
4. **Доставка:** СДЭК (пока только она)
5. **Регистрация:** по телефону через SMS
6. **Админка:** заказчик сам меняет товары, цены, коллекции
7. **Без мобильного приложения** — только адаптивная вёрстка

Заказчик готовит: ключи API, политику конфиденциальности, оферту, домен (пока тест на Git + Vercel).

**Референсы дизайна:** [lingeriemerci.ru](https://lingeriemerci.ru/) (основной), [preludiiya.ru](https://preludiiya.ru/)

## Как запустить с нуля

```bash
cd "C:\Users\inost\Documents\Бельё"   # или Nega, если переименовали
npm install
copy .env.example .env                # указать DATABASE_URL (необязательно для UI)

```

Сайт открывается на http://localhost:3000 **без базы данных** — показываются заглушки товаров и локальные placeholder-картинки из `public/placeholders/`.

С базой:

```bash
npm run db:push
npm run db:seed
```

- Перетаскивание мышью (ЛКМ) и свайп на тач-устройствах

## Схема базы данных (Prisma)

Уже описано в `prisma/schema.prisma`:

- **User** — телефон, ФИО, баллы
- **Session** — сессии авторизации
- **Product** — товар (название, slug, цена, описание, SKU)
- **ProductVariant** — размер, цвет, остаток
- **ProductImage** — картинки
- **Collection** — коллекции
- **Order / OrderItem** — заказы
- **PointTransaction** — история баллов
- **SiteSettings** — название магазина, % начисления баллов

## Известные особенности и решения

| Проблема | Решение |
|----------|---------|
| Папка с кириллицей `Бельё` ломала `create-next-app` | Имя пакета `nega-shop` в `package.json` |

## Завтра: деплой для показа заказчику

**Цель:** ссылка вида `https://nega-shop.vercel.app` — бесплатно на старте (Vercel Hobby + текущая или отдельная тестовая БД).

### Чеклист деплоя
1. [ ] Залить код на **GitHub** (если ещё не залит)
2. [ ] **Vercel** → Import repository → Framework: Next.js
3. [ ] **Environment Variables** в Vercel:
   - `DATABASE_URL` — Yandex Cloud PG (или отдельная demo-БД + seed)
   - `ADMIN_EMAIL`, `ADMIN_PASSWORD` — для seed админа
   - `SESSION_SECRET` — случайная строка 32+ символов
   - `NEXT_PUBLIC_SITE_URL` — URL деплоя после первого билда
   - опционально: `RESEND_API_KEY`, `EMAIL_FROM`, `CRON_SECRET`
4. [ ] После деплоя: `npx prisma db push` и `npm run db:seed` **против prod БД** (локально с prod `DATABASE_URL` или через CI)
5. [ ] Проверить: главная, каталог, товар, корзина, checkout, `/admin`, `/order/track`
6. [ ] Отправить заказчику ссылку
